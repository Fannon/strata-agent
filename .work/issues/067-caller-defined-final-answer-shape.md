Status: DEFERRED, not selected. Discovered in the authorized 065 AppWorld study.
Dependencies: delivered 058 exact JSON selection; distinct from 063 required-effect completion evidence.

Seven of 11 primary-successful checked GLM attempts submitted the accepted scalar/string answer but selected an object for final delivery. The host faithfully delivered that object. All seven remained valid primary AppWorld successes, but failed the frozen supplementary final/submitted-answer consistency rule. See [report](../../docs/application-study.md).

Exact delivery currently guarantees the selected JSON value, not the caller's desired result shape or correspondence to a prior submission. An optional explicit caller-provided result schema or completion constraint could reject the wrong selection. Merely inferring intent from arbitrary task text or adding another generic completion framework is not justified.

If selected for a concrete caller, define the acceptance contract first; scope checks to final selection so exploratory program results remain usable. Preserve already acknowledged effects and distinguish invalid final selection from business-task failure. Compare any prompt-only alternative fairly, and do not tune on the published evaluation cells. No implementation or paid follow-up is selected by this capture.
